# Yigithan Burak Cetin — Data Analyst Portfolio

Personal portfolio website showcasing my data analytics projects, skills, and certifications.

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript

## Features

- Dark theme with gradient accents
- Responsive design (mobile-friendly)
- Scroll reveal animations
- Profile picture with gradient border
- Skill icons for SQL, Power BI, Excel, Python
- Project cards with GitHub links
- Certification cards with Udemy certificate links
- Contact section with email, LinkedIn, and phone

## Sections

- **Hero** — Introduction and profile picture
- **Skills** — SQL, Power BI, Excel, Python, Data Cleaning, Data Validation
- **Projects** — E-Commerce Analysis, Coffee Shop Dashboard
- **Experience** — Work history timeline
- **Certifications** — Udemy courses and IELTS
- **Contact** — Email, LinkedIn, phone
